New to Linux? Start with these five ideas
pwdWhere am I?

Prints the directory you are currently working in.

lsWhat is here?

Lists files and folders. Try its manual to discover options.

cdMove around

Changes directory. cd .. moves up one level.

catRead a file

Prints the contents of a text file to the terminal.

manAsk Linux for help

For example, man ls. Press q to leave a manual page.
